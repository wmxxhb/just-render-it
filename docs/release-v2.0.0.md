## Windows Typora 1.2.4 公式语法兼容补丁

为匹配构建的 Typora 1.2.4 增加 LaTeX 分隔符、公式围栏和独立环境识别，保留原始公式分隔符，提供本地备份与卸载恢复。

### 下载与使用

下载本页附件 **`typora-math-compat-v2.0.0.zip`**，完整解压，保存文档并完全退出 Typora，双击 **`安装.cmd`** 后重启。内联公式需要在 Typora 设置中启用。

- `检查.cmd`：只读校验当前安装与备份。
- `卸载.cmd`：退出 Typora 后恢复原版程序。
- `示例.md`：支持语法与带编号的多行公式示例。

无需 Python、Node.js 或联网。支持的程序文件由版本号和 SHA-256 共同限定；其他版本或其他构建会停止安装。

### 支持内容

- `$...$`、`\(...\)` 内联公式。
- `$$...$$`、`\[...\]` 单行、跨行及混合布局。
- `math` 反引号/波浪线围栏，以及常见独立 LaTeX 公式环境。
- 多行对齐、公式编号、原始分隔符序列化与表格内公式竖线保护。
- 原版文件备份、重复安装识别、精确文件核验及写入失败撤回。

### 验证

实际 Typora 的渲染与编辑已完成用户测试；11 项独立辅助代码测试、Windows PowerShell 5.1 的 12 项安装与恢复检查，以及原生解析器集成用例通过。公开 CI 仅运行无需 Typora 私有文件的检查；详见仓库开发文档。
